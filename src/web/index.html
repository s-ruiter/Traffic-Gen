Verkeersmix

Bepaal welk soort verkeer hoe vaak voorkomt. Gewicht 0 schakelt een groep uit.

Beveiligingstests. Malware-test gebruikt alleen standaard, onschadelijke testbestanden (EICAR, WICAR); een download die door de FortiGate wordt doorgelaten telt als gemist. IOC / botnet-gedrag stuurt alleen DNS-queries (DGA-patronen, DNS-tunneling, dynamic DNS, mining-pools) en op verzoek kale TCP-connects, zonder data of downloads. Beide staan standaard uit; zet ze alleen aan op netwerken waar je dit mag testen. De extra IOC-schakelaars staan onder Instellingen.

Netwerk

Het testverkeer verlaat de LXC via een apart bronnetwerk; de management-interface blijft ongemoeid.
